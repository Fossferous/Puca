Install Púca as an app opens Púca in Chrome, Edge or another Chromium browser and offers to install it as its own window, with an icon in your Start menu or app drawer — no download from this page. Púca asks first; nothing is installed until you tap.

On iPhone or iPad, add the web app to your Home Screen — there is no App Store app. Steps and limits are just below. On a Mac, use Open in your browser; current Safari, Chrome and Firefox all encrypt calls frame by frame, and a browser too old to do it is told so before you join rather than quietly downgraded.

The Android app keeps itself up to date: each time it starts it fetches the current version from this server and applies it before opening. There is no switch for that, and it happens before you sign in — it is how a broken version gets fixed and how every device here stays on the same one. Only updates signed by this server are accepted, and an older one is refused. The Windows app is different: there, updating is optional and off unless you turn it on.

Púca on iPhone & iPad — there is no App Store app. Instead you add Púca's web app to your Home Screen from Safari: it gets its own icon and opens full screen, like an app. There are two ways: one tap (a small settings file), or the Share steps.
Install with one tap

iPhone installs a profile only from Safari. Open this page in Safari to use one tap, or follow the Share steps below.

Install with one tap
  1. Tap the button, then Allow when Safari asks to download a configuration profile.
  2. Open Settings and tap Profile Downloaded near the top. (Not there? Go to General → VPN & Device Management and tap Púca.)
  3. Tap Install in the corner, enter your passcode, then tap Install again and Done.
  4. Open Púca from your Home Screen and sign in there.

What the file contains, and nothing else: one Home Screen icon named Púca that opens https://__APP_HOST__ full screen. No certificates, no restrictions, no other settings — nothing that lets anyone manage or watch your phone. You can remove it any time (press and hold the icon and choose Remove App, or delete the profile in VPN & Device Management).

“Not Verified” is what iPhone shows for any profile that is not signed with a certificate Apple trusts. This one is not signed: that needs a paid certificate, and it would add nothing here, because the file can only add this one icon. It is generated from this server's own address, so it points at this server and nowhere else.

Which should you pick? The Share steps below are the route Apple documents for Home Screen web apps, so they stay the recommended one. The one-tap icon opens the same web app full screen, but we have not been able to confirm on a real iPhone that it behaves identically — in particular, Apple documents notifications for web apps added with Share and says nothing about this route. If something does not work after the one-tap install, remove it and use the Share steps.

Or add it yourself with Share (recommended):

  1. Open __APP_HOST__ in Safari.
  2. Tap Share (the square with an arrow pointing up).
  3. Tap Add to Home Screen (scroll down the list if you do not see it).
  4. Tap Add. Open Púca from your Home Screen and sign in there.

What is different from the Android and Windows apps:

  • No notifications while Púca is closed. iPhone can send them to a web app; Púca does not use that yet, so new messages show up when you open it.
  • Calls are encrypted end to end. Safari encrypts a call's sound and video frame by frame through the standard browser feature Firefox uses too, so with Require encryption for calls on (the default) you hear and are heard as on the other apps. Firefox runs the same code and has been tested; an iPhone has not been tried yet. If a call there shows that the browser cannot encrypt, Púca says so before you join and keeps your microphone, camera and screen out of the call rather than send them where your server could read them. Channels in SFU mode use a different encryption that Safari may support; that has not been tried on an iPhone either.
  • My Devices. An iPhone cannot be controlled from elsewhere and cannot share its own screen. Controlling a Windows PC from it uses the same code as on Android, which has not been tried on an iPhone.
  • Photos work. Safari reads iPhone photos (HEIC) itself: Púca turns one into a JPEG on the phone before it is sent, without the location the camera saved with it.
  • It keeps its own sign-in, separate from the one in Safari, so sign in once inside the Home Screen app.

Getting started
1. Download and run the installer (Windows) or the .apk (Android), or add the web app to your Home Screen (iPhone and iPad).
2. Open Púca.
3. Click Register, enter your invite code, choose a username & password, and you're in.

Registration is invite-only — ask the server owner for a code.

The app connects to __API_HOST__. Windows SmartScreen may warn on first run (unsigned app) — choose More info → Run anyway. On Android, allow install from your browser and accept the app's own signature.

Check the file before you run it. The Windows installer is not code-signed; instead every file on this page is listed with its SHA-256 in SHA256SUMS.txt. On Windows, open a command prompt in your Downloads folder and run certutil -hashfile Puca-Setup.exe SHA256; on Linux or Android, sha256sum <file>. The hash printed must match the line for that file. If it does not, the download is not what this server published — do not run it.

Antivirus may also quarantine the remote-access components (a generic detection such as Trojan:Win32/Bearfoos.B!ml). It's a false positive, but an understandable one: those files capture the screen, inject input and can install a system service — what every remote-desktop tool does, and what a trojan does too. Unsigned, that's enough for a heuristic to act. Remote access is opt-in; chat and voice work without it. If you'd rather not have that code on your machine at all, the Lite build above doesn't include it. This build contains no remote-access code at all — no screen capture, no input injection, no system service. Chat, voice and file transfer all work the same as the full build.
