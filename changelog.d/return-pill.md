### Fixed

- **The way back to a remote-control session no longer covers the message box.**
  With the stage put away to chat (**Chat** on a phone, **Back to Púca** on a
  computer), the blue "Return to remote device" pill sat in the bottom-right
  corner over everything: on a phone with the keyboard up it covered the message
  box and Send, with the keyboard down it covered the tabs at the bottom (a tap
  on Chat brought the remote screen back instead), and on a computer it covered
  Send. It also named the session by a code instead of the computer. It is now a
  button that says **Return to** and the computer's name, in a bar the app makes
  room for: along the bottom of the window on a computer, and above the tabs (and
  the voice bar in a call) on a phone, with the message box above it. While the
  phone's keyboard is up it steps aside, like the tabs. A dialog or sheet opened
  over the chat (a member's profile, Settings, Server Settings, Edit Channel,
  Create Channel) or in the Devices view (Share) now covers it, so a tap meant
  for the dialog no longer brings the remote screen back. It can be reached with Tab and pressed with Enter or
  Space, and its live dot keeps still for anyone who asked their system for less
  motion. Comes with the update (no new install, no server update).
- **A new remote-control session opens on screen, not put away.** If a
  session ended while it was put away to the chat, the next Connect showed only
  the way back to it instead of the other computer's screen, and so did a
  second computer connected while the first was put away. A session that newly
  opens is now shown. A session you put away stays away until you press its
  bar, also when a computer you connected to after it ends its session, and
  when it moves by itself because someone signed in at that computer or it
  locked. Comes with the update (no new install, no server update).
