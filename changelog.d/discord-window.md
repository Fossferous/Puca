### Added

- **Discord in a window of its own, in the Windows desktop app.** **Settings → Advanced → Show Discord in the server rail** (off by default) puts a Discord button in the server rail. It opens Discord's own website in a window of its own: you sign in on Discord's page and use your DMs and servers as yourself, and pressing the button again brings that window forward, at the size and place you left it. Púca's code never runs in that window, and Púca cannot read the page, your messages or your Discord sign-in. Your Púca server never sees any of it: the window talks to Discord directly. It is a separate program with no part of Púca in it, and its sign-in is kept in a separate store on this PC. Discord's own pages stay in the window, and the title bar names the site it is on. Links to other sites open in your browser, and only when you click them; a link that would start another program does nothing. Only Discord's own site can ever be granted anything, and only after a question: the microphone and camera through the window's own question, notifications through Púca's (OK allows them, and Windows then shows Discord's own). **Sign out of Discord and clear its data on this PC**, beside the switch and offered again when you turn it off, closes the window and deletes everything Discord stored on this PC. Downloads go to your Downloads folder and nothing opens by itself. Calls work, with push to talk only while the window is focused. `docs/DISCORD.md` explains how it is kept apart, with the code to check, and the risks that remain. Works in the full and the Lite app alike, and not in the web app or on phones. It needs this version of the desktop app (installer); nothing changes on the server.
