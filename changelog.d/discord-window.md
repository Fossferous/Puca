### Added

- **Discord in a window of its own, in the Windows desktop app.** **Settings → Advanced → Show Discord in the server rail** puts a Discord button in the server rail. It opens Discord's own website in a window of its own: you sign in on Discord's page and use your DMs and servers as yourself, and pressing the button again brings that window forward, at the size and place you left it. Púca does not see, keep, send or press anything in that window. It runs as a separate Púca program with its own cookies and storage, apart from Púca's, and with none of Púca's features or data in it. Discord's own pages stay in the window and links to other sites open in your browser. The first time Discord asks to show notifications, Púca asks whether to allow them (the window has no question of its own for this); say yes and Windows shows Discord's notifications, which Púca never sees. Off by default, in the full and the Lite app alike, and not in the web app or on phones. It needs this version of the desktop app (installer); nothing changes on the server.
